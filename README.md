# Проект "Поиск вакансий"

## Описание
Проект позволяет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в БД и работать с ней, используя различные фильтры связанные с наименованиями вакансий и размерами заработной платы

## Установка
1. Клонируйте репозиторий
2. Установите зависимости
3. Настройте файл .env, используя шаблон .env.example

## Использование
1. Запустите создание таблиц и загрузку данных через модуль data_loader.py 
*примечание - список компаний, чьи вакансии будут загружаться можно отредактировать в модуле api.py, в функции "get_companies", в переменной companies. Необходимо указать название компании ф формате string
   
2. Откройте файл main.py. Далее вы можете нажать на:
"1" - «Получить список компаний и количество вакансий» - Приложение выводит информацию о всех компаниях и их вакансиях из БД;
"2" - "Получить все вакансии" - Выводит список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию;
"3" - "Средняя зарплата по вакансиям" - Выводит среднюю зарплату по вакансиям;
"4" - "Вакансии с зарплатой выше средней" - Выводит список всех вакансий, у которых зарплата выше средней по всем вакансиям;
"5" - "Вакансии по ключевому слову" - Пользователю предлагается ввести ключевое слово, после этого приложение выводит список всех вакансий, в названии которых содержится это слово;
"6" - "Выход" - завершение работы приложения.

4. Приложение в формате "из коробки" не предусматривает взаимодействие с файлами (чтение и запись). Если вы желаете настроить процесс записи данных в файл или чтения данных из файла, в модуле file_manager есть примеры простых функций для чтения данных из файла и записи в него (в формате json).

### Классы и методы проекта:
- **DBManager**: Класс для взаимодействия с БД
- - **create_tables**: Метод для создания новой таблицы
- - **insert_companies**: Метод для внесения в БД данных о компаниях-работодателях
- - **insert_vacancies**: Метод для внесения в БД данных о вакансиях
- - **get_companies_and_vacancies_count**: Метод, который получает список всех компаний и количество вакансий у каждой компании.
- - **get_all_vacancies**: Метод, который получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
- - **get_avg_salary**: Метод, который получает среднюю зарплату по вакансиям.
- - **get_vacancies_with_higher_salary**: Метод, который получает список всех вакансий, у которых зарплата выше средней по всем вакансиям
- - **get_vacancies_with_keyword**: Метод, который получает список всех вакансий, в названии которых содержатся переданные в метод слова
- - **close**: Метод, который закрывает соединение с БД

### Прочие функции проекта:
- **get_companies**: Возвращает список из компаний, вакансии которых ищет приложение.
- **get_vacancies_for_company**: Получает вакансии для компании по employer_id.
- **setup_database** - Получает компании и вакансии для них и вставляет их в БД
